# Code Challenge

A repository for code challenge solutions and practice.

## Project Overview

This project is intended to hold solutions to programming challenges. Since the repository currently has no project-specific implementation or language configuration documented, add challenge solutions with their own setup and run instructions.

## How to Use

1. Browse the repository for the challenge you want to explore.
2. Read any instructions included with that solution.
3. Install the runtime or dependencies specified there, then run the solution as documented.

## Adding a Solution

- Organize each solution so its challenge and purpose are easy to identify.
- Include the challenge prompt or a reference to it, when appropriate.
- Document how to run the solution and provide examples or tests where useful.
- Explain the approach and relevant time or space complexity.
